# Tool catalogs

`bsl-language-server-1.0.7.json` is a generated factual catalog of diagnostic
metadata from BSL Language Server v1.0.7. The file records its exact upstream
revision, source URL and LGPL-3.0-or-later source license. Regenerate it with
`scripts/generate-bsl-diagnostic-catalog.mjs`; do not edit individual rules by
hand.
