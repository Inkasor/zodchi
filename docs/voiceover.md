# Озвучка и дубляж

Workflow voiceover записывает реплики на выбранном языке через gpt-realtime-2.1-mini. На входе нужен готовый текст с временными окнами. Для дубляжа сначала переведите и укоротите реплики под монтаж, затем передайте их вместе с подсказками о произношении.

## Выбор голоса и языка

Команда `zodchi flow voiceover voices` показывает каталог голосов и рекомендуемые отправные варианты по языкам. OpenAI рекомендует начинать с marin или cedar. Характер звучания зависит от текста, языка и указаний к подаче. Проверьте на двух репликах из своего ролика. [Голоса Realtime](https://developers.openai.com/api/docs/guides/realtime-conversations#voice-options)

| Голос | Где попробовать |
| --- | --- |
| marin | Выразительная речь в шортсе, короткие объяснения |
| cedar | Размеренный рассказ, технические названия и числа |
| alloy | Спокойная нейтральная дикция |
| ash | Разговорная авторская подача |
| ballad | Тёплый рассказ с паузами |
| coral | Ведущий или динамичная подводка |
| echo | Сдержанный диалог и сухая шутка |
| sage | Спокойное объяснение с фактами |
| shimmer | Лёгкая и живая подача |
| verse | Энергичный хук или реплика персонажа |

Для русского выберите ru-RU, для французского fr-FR, для английского en-US или en-GB. Также подходят языковые теги со скриптом и регионом, например sr-Latn и pt-BR. Язык и вариант произношения передаются модели в инструкциях. Если голос опущен, Зодчи выбирает голос по каталогу. Для другого тега начальный вариант — marin.

## Запуск

Укажите существующую папку проекта в dir. Время отсчитывается от начала монтажа. Сохраните JSON в проекте.

```json
{
  "dir": "/absolute/path/to/short",
  "language": "ru-RU",
  "voice": "cedar",
  "speed": 1.0,
  "style": "Живой авторский голос для короткого ролика. Энергичное начало, чистая дикция.",
  "pronunciation": "А́стра с ударением на первом слоге. 1С произносить «один эс».",
  "durationMs": 6200,
  "cues": [
    {
      "startMs": 200,
      "endMs": 3000,
      "text": "Я попросил Астру поработать в 1С.",
      "spokenText": "Я попросил А́стру поработать в один эс.",
      "direction": "Акцент на «поработать». Короткая пауза после «Астру»."
    },
    {
      "startMs": 3400,
      "endMs": 5900,
      "text": "Покажу, что вышло.",
      "direction": "Лёгкое удивление. Закончить уверенно."
    }
  ],
  "paid": true
}
```

```text
zodchi flow voiceover plan --args <file.json>
zodchi flow voiceover --args <file.json> --detach
zodchi flow status <run-id>
zodchi flow voiceover --resume <run-id>
```

Команда plan проверяет все поля заранее и показывает число будущих запросов. Один запуск принимает до 60 реплик, до 25 секунд на реплику и до 10 минут суммарного монтажа. Если durationMs опущено, дорожка заканчивается по последнему окну. Поле spokenText задаёт вариант для произнесения, когда в титрах нужны цифры, сокращения или исходное написание.

Поле style задаёт общую манеру. В direction каждой реплики укажите, где снизить тон, улыбнуться, сделать паузу или выделить слово. Для точных пауз задайте фразы отдельными репликами с нужным интервалом. Параметр speed от 0,25 до 1,5 регулирует скорость готового звука. Задавайте его для дорожки или отдельной реплики. Ритм и интонацию самой речи описывайте в style и direction. [Управление речью](https://developers.openai.com/api/docs/guides/voice-prompting) · [Параметры Realtime](https://developers.openai.com/api/reference/resources/realtime/client-events)

Для записи задайте OPENAI_API_KEY в окружении запуска и paid в аргументах. Каждый дубль — один отдельный ответ Realtime с пределом выходных токенов. Из обычного Codex и Claude Code команды запускают общий CLI и используют журнал на том же компьютере.

## Результат

В журнале есть WAV каждой реплики, ответная транскрипция, время до первых аудиобайт, usage и SHA-256. Когда все реплики помещаются в свои окна, общий файл voiceover.wav содержит PCM16 mono 24 кГц с их исходными паузами по таймлайну. Его можно положить на отдельную дорожку в монтаже, сохранив музыку и эффекты из источника.

Если реплика длиннее окна, результат timing-review сохраняет все отдельные WAV. Прослушайте дорожку и по необходимости сократите реплику или сдвиньте границу кадра. ScriptMatch указывает, совпадает ли транскрипция с выбранным текстом после нормализации пробелов и пунктуации. Ударения, эмоции и естественность проверьте на слух.

Resume использует закреплённые входы и сохранённые реплики. Если соединение оборвалось после записи платного намерения, команда status покажет остановленный шаг. После сверки журнала можно явно разрешить новый дубль командой `zodchi flow voiceover --resume <run-id> --rerun "cue 2"`. Этот дубль может снова потратить деньги API-проекта. [Оплата Realtime](https://developers.openai.com/api/docs/pricing)
