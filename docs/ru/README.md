# Zodchi

[English](../../README.md) · [Русский](README.md)

Zodchi помогает Codex и Claude Code доводить реальную работу над проектом до проверенного результата. Поддержка Cursor доступна в preview-режиме.

Вы описываете желаемый результат в обычном чате. Zodchi может подготовить план, распределить работу между подходящими моделями, сохранить важный контекст проекта, запустить его проверки и зафиксировать принятые решения. Вы по-прежнему решаете, что можно менять, публиковать, развёртывать и считать завершённым.

<section id="kak_eto_rabotaet" status="accepted">

## Как это работает

1. Настроечный чат устанавливает Zodchi и изучает проект, доступные модели, инструменты и существующие документы.
2. Zodchi предлагает схему работы. До вашего подтверждения ничего не регистрируется.
3. В чате проекта один раз введите `/zodchi`. Дальше общайтесь в этом чате обычными сообщениями.
4. Перед серьёзной работой Zodchi показывает, как собирается действовать: какое нужно качество, следует ли упорно доводить цель до конца, насколько тщательно проверять результат и доступны ли несколько независимых планировщиков.
5. Zodchi выполняет работу, проверяет результат и либо завершает задачу с доказательствами, либо объясняет реальное препятствие.

Остальные чаты продолжают работать как обычно. Закрытие чата завершает режим Zodchi в нём. В preview-режиме Cursor `/zodchi` закрепляется как Custom Mode текущего чата.

</section>

## Для чего подходит

Zodchi можно использовать для разработки программ, 1С, веб- и Unity-проектов, исследований и работы с данными, инфраструктуры и выпусков, маркетинга и производства контента.

Готовые рабочие процессы — это отправные точки, а не обязательные шаблоны. Во время настройки Zodchi изучает, как проект уже устроен, и предлагает только полезный контроль. Вы сами выбираете важные документы и правила и можете позже изменить этот выбор, не удаляя сами файлы.

Разные модели могут выполнять разные задачи. Обычную работу можно поручать быстрым моделям, а сильные использовать для планирования, сложных решений и независимой проверки.

</section>

<section id="ustanovka" status="accepted">

## Как попробовать

Откройте новый чат Codex, Claude Code или Cursor и отправьте:

> Открой https://github.com/Inkasor/zodchi, прочитай `ONBOARDING_PROMPT.md`, установи последнюю версию Zodchi и настрой её для моего проекта. Техническую часть выполни сам, а меня спрашивай только о решениях, которые нельзя безопасно определить автоматически.

Сохраните этот настроечный чат: позже в нём можно добавлять проекты, менять модели и настраивать способ работы.

Codex требует отдельно доверить локальные hooks. Откройте `/hooks`, одобрите обе записи Zodchi и создайте новый чат проекта; включённые переключатели сами по себе не означают одобрение.

Для Zodchi нужен Node.js 24 или новее. Windows и macOS поддерживаются. Linux проходит автоматические проверки, но пока считается экспериментальным.
