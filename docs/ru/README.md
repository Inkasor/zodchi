# Zodchi

[English](../../README.md) · [Русский](README.md)

Zodchi превращает один обычный чат с моделью в управляемую команду для реальной работы над проектом.

Вы своими словами описываете, что хотите получить. Zodchi определяет вид работы, передаёт каждому специалисту только нужный контекст, запускает подходящие проверки, фиксирует принятые решения и возвращает понятный ответ в тот же чат.

Обычные сообщения остаются обычными сообщениями. Для явного запуска используйте `/zodchi <задача>` или короткую форму `/zod <задача>` в Codex и Claude Code. Команда без аргументов может взять непосредственно предшествующий содержательный запрос, только если это однозначно.

## Зачем это нужно

- Результат становится качественнее: планирование, выполнение, проверка и документирование идут по понятному рабочему процессу, а не по одному огромному промпту.
- Модели обходятся дешевле: простую работу выполняют доступные модели, а сильные подключаются там, где действительно нужно сложное решение.
- Контекст не тратится впустую: факты и документы проекта собираются программно и передаются только тем ролям, которым они нужны.
- Код находится точнее: детерминированный лексический поиск проходит по compiler-связям TypeScript/JavaScript и структуре BSL до передачи исходников модели; векторная база для этого не требуется.
- Качество становится предсказуемее: код, документы, выпуск и другие результаты проходят проверки, настроенные для проекта.
- Пользователь остаётся в привычном чате и общается нормальным человеческим языком.

</section>

## Что можно делать

Zodchi может организовать разработку программ, исследования, маркетинг и производство контента, проектирование игр, работу с изображениями и звуком, данные, выпуск версий и разбор неисправностей. Роли и рабочие процессы настраиваются, поэтому одна система подходит для очень разных проектов.

Важные решения, публикация, доступы, развёртывание и субъективная приёмка результата остаются за владельцем.

</section>

## Начало работы — одним сообщением

Создайте новый чат в Codex или Claude Code и отправьте ему ссылку на репозиторий с такой просьбой:

> Открой https://github.com/Inkasor/zodchi, прочитай `ONBOARDING_PROMPT.md`, установи последнюю версию Zodchi и настрой её для моего проекта. Техническую часть выполни сам, а меня спрашивай только о решениях, которые нельзя безопасно определить автоматически.

Сохраните этот настроечный чат. В нём потом можно добавлять проекты, менять модели, создавать роли и настраивать рабочие процессы под себя.

Release candidate 0.6 использует один кроссплатформенный архив и нацелен на Windows и macOS; установка на Linux остаётся экспериментальной до живого внешнего acceptance. Windows принят локально, а owner acceptance на macOS остаётся обязательным release gate. Поддерживаемый вход работает через Codex и Claude Code. Другие агентские программы можно подключать как исполнителей, если они установлены и настроены локально.

</section>
