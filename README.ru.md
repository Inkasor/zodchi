# Zodchi

[English](README.md)

Zodchi запускает общие рабочие процессы для Codex и Claude Code. Движок на Rust готовит контекст, вызывает модели по ролям, выполняет проверки и записывает шаги. Продолжить запуск можно из другого клиента.

[Установка](#установка) · [Рабочие процессы](#рабочие-процессы) · [Исходники](#исходники)

## Установка

Дайте Codex или Claude Code ссылку на этот репозиторий и попросите **установить и подключить Зодчи**. В инструкции описано, как выбрать и проверить сборку, подключить клиенты и убедиться, что установка работает. [Инструкция по установке](docs/install.ru.md) · [Скачать выпуск](https://github.com/Inkasor/zodchi/releases/latest)

Текущий чекаут можно [собрать и установить из исходников](docs/install-from-source.ru.md).

## Рабочие процессы

Команда `zodchi flow list` показывает процессы, доступные в проекте. [Старт и продолжение запуска](docs/flow.md#running-it) устроены одинаково в Codex и Claude Code.

| Задача | Руководство |
| --- | --- |
| Превратить цель в бриф | [Подготовка брифа](docs/design-brief.md) |
| Сделать и проверить правку кода | [Пакет кода](docs/flow.md) |
| Протестировать веб-приложение или игру | [Приёмка](docs/acceptance.md) |
| Собрать и проверить ролик | [Видео](docs/flow-video.md) |
| Загрузить принятый ролик приватно | [Загрузка на YouTube](docs/youtube-publish.md) |

Остальные процессы есть в [общем каталоге](workflows/catalog.json). Модели выбираются через [настройки ролей](docs/model-roles.md).

## Исходники

| Папка | Что в ней |
| --- | --- |
| [rust](rust/README.md) | Cargo workspace с CLI, движком процессов, шлюзом моделей и сервером |
| [rust/crates/zodchi-flow](rust/crates/zodchi-flow) | Реализации процессов, промпты и схемы |
| [workflows](workflows/catalog.json) | Общий каталог процессов |
| [skills](skills) | Общие инструкции для обоих клиентов |
| [roles](roles) и [models.json](models.json) | Промпты ролей, схемы ответов и модели по умолчанию |
| [plugins](plugins) | Навыки для клиентов и дополнительные агенты Claude Code |
| [install](install) | Команды сборки переносимого пакета из исходников |
| [scripts/e2e](scripts/e2e) | Сквозные проверки и тестовые данные |

CLI собирается из корня репозитория.

```sh
cargo build --release --locked --manifest-path rust/Cargo.toml
```

Порядок проверок описан в [руководстве по verify](docs/verification.md). Для настройки доступа есть [правила работы с подписками](docs/subscriptions.md) и [инструкция для корпоративных форков](docs/fork.md).
