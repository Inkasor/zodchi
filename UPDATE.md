# Обновление Zodchi

Папка программы и папка личных данных разделены. Обычное обновление заменяет только программу и не трогает проекты, настройки, базы и историю запусков.

## Рекомендуемый порядок

1. Скачайте архив и файл контрольных сумм из GitHub Release.
2. Проверьте SHA-256 архива.
3. Распакуйте архив во временную папку.
4. Запустите безопасное обновление:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\install-or-update.ps1 -Source <распакованная-папка> -Destination <папка-Zodchi>
```

Скрипт проверит состав поставки, заменит установленную версию атомарно и не оставит постоянную резервную копию после успешной замены. Если изменился Codex hook, скрипт сообщит, что доверие к нему нужно подтвердить заново.

Перед изменением основной или дополнительной версии отдельно сделайте штатный снимок локальных баз через команду `backup` из `QUICKSTART.md`.
